## 🌟 Live Project Concept
This project presents a **fully visual, interactive periodic table** containing **all 118 chemical elements**, designed using **CSS Grid** and modern UI practices.  
Each element is color-coded by category and reveals detailed information when clicked.

> 📌 Ideal for **students, educators, and front-end learners**

---

## 🎯 Objective
To design an **online periodic table** that:
- Displays all **118 chemical elements**
- Follows the **standard periodic table structure**
- Is **interactive, responsive, and visually engaging**
- Uses **CSS for layout and styling**

---

## 🧠 How It Works (Algorithm)

### 🧩 Step 1: Data Initialization
- Load dataset of all 118 elements
- Store properties:
  - Atomic number
  - Symbol
  - Name
  - Atomic mass
  - Category
  - Electron configuration
  - Phase
  - Discovery details

---

### 🎨 Step 2: UI Rendering
- Create **10 × 18 CSS Grid**
- Place elements in correct groups & periods
- Use empty grid cells for spacing
- Apply **color-coding** by category

---

### 🖱 Step 3: Interactivity
- Click any element
- Display detailed information in an info panel
- Highlight selected element

---

### 📱 Step 4: Responsive Design
- Desktop → Full grid layout
- Mobile → Compact & scrollable layout
- CSS media queries ensure adaptability
